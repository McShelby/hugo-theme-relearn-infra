Hostile Input

Every place an author can hand the theme a value that ends up in an attribute, filled with values made to break out of it:

  • Boxes - button, callout, badge and icon
  • Figure - Hugo’s figure shortcode, drawn by the theme
  • Images and Links - the partials behind the image and link render hooks
  • Markdown - the render hooks, reached through Markdown alone
  • Front Matter - a title and terms, which reach menu, breadcrumbs and lists
  • Resources - a file name the theme turns into a link
  • Cards - URLs a card runs or links
  • Menu URL and Menu Page Ref - where a page’s menu entry leads instead, next to a menu from the configuration
