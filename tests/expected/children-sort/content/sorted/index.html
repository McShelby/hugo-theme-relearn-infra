Sorted

One listing per documented sort value, over the same four pages. Each block carries the criterion in its class, so the order below a class either matches that criterion or the sort did not happen.

title Alpha, Bravo, Charlie, Delta
date Delta, Charlie, Bravo, Alpha
modifieddate Charlie, Delta, Alpha, Bravo
publishdate Bravo, Delta, Alpha, Charlie
expirydate Alpha, Charlie, Bravo, Delta
length Delta, Bravo, Charlie, Alpha

card

A card template is handed the sort it was listed under, so sortprobe can print it back. Reaching that template at all is what shows cardtemplate arrived with it.
