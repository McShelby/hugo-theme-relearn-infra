Unknown classes

A class the theme knows nothing about is dropped here rather than passed to the element - unlike the same class handed to the partial by a template, which the Template page shows arriving on the element. The asymmetry is the theme’s, and this is where it would show up if it changed.

A custom class starting with no is not an effect being switched off, and is dropped for the same reason rather than for that one.
