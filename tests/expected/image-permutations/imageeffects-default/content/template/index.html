Template

The theme documents calling its image partial from a template, passing effects as attributes. That is the highest layer of the effect stack, above the URL, the front matter and the site configuration - and the only layer that can hand the partial an HTML attribute directly.

A fixture-local shortcode makes the call, so these are template calls rather than markdown images.
