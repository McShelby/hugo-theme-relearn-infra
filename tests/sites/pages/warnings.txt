# The `text`, `invalid`, `layout` and `legacy` sections provoke these on purpose.
#
# Here the warning is the assertion, not an accepted defect: a listing that
# stopped warning, or started warning differently, would be a change in the
# theme's contract with an author - one who mistyped a parameter, or one still
# using the deprecated `children` shortcode and relying on the `pages` call its
# warning names.
#
# Listing each message in full rather than accepting `invalid parameter` or
# `DEPRECATED shortcode 'children'` wholesale is deliberate. A blanket entry
# would also swallow a warning some other listing started emitting by accident,
# which is the thing this file is meant to catch. The file path each message
# starts with is left out, as it depends on where the site was built.
